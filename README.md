# Caesar Cipher Project 🔐

A Python-based Caesar Cipher encryption and decryption program.

## Features
- Encode messages
- Decode messages
- Handles symbols and numbers
- Restart option using loops
- Shift logic using modulo operator

## Technologies Used
- Python

## Concepts Practiced
- Functions
- Loops
- String manipulation
- Lists & indexing
- Debugging
